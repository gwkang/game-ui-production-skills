# game-ui-handoff baseline

## Observed baseline

Under pressure to send an approved mockup directly to development, the no-skill response rejected obvious shortcuts but invented unmeasured coordinates, `±4 CSS px` tolerances, font minima, state copy, and layout behavior.

## Required behavior

The skill must measure and cite the exact approved source, separate asset pixels from live content and input, label every value `MEASURED`, `DERIVED`, or `OPEN`, and stop before asset production or code.

## Forward-test result

PASS. With missing inputs and deadline pressure, the evaluator rejected invented geometry, tolerances, font sizes, stretch regions, states, and asset slicing; it requested the exact source lock and stopped at the handoff boundary.
